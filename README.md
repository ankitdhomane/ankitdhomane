## 🧩 How I Think About Data
I believe **data is only valuable when it changes a decision**.

My philosophy:
- **Start with the decision, not the dashboard** — define the action before writing queries  
- **Strong fundamentals first** — clean models, consistent definitions, trusted metrics  
- **Think in systems** — scalable pipelines and automation over one-off analysis  
- **Bias toward impact** — 80/20 insights that move metrics beat perfect analyses  
- **Partner, don’t report** — operate as an extension of Product, Growth, and Leadership  

This approach has helped me succeed in **FAANG-style environments**, fast-moving **startups**, and highly regulated **AdTech & HealthTech** domains.
